Placement test — before / after the recheck fix

The change: a recheck used to require 3 of 3 fresh questions, which made a 2/3 indistinguishable from a 0/3. It now tolerates one miss (RECHECK_MISSES_ALLOWED in placement.js).

Every scenario below is run as the same learner twice: once under the old rule and once under the new one. The “after” column is driven by clicking the real quiz UI, so it is shipped behaviour rather than a description of it; the “before” column is the verified rule model, since that code no longer exists to click. Nothing here writes to your progress.

For the full standalone analysis of either rule set, see placement-sim.html.

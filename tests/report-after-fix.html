What each rule change would buy

The same Matrix A, B and C learners, replayed under alternative rules. “Stranded” counts runs that end on a module the learner was offered a recheck on and failed. Model only — these variants do not exist in the app, and nothing here changes it.

Only “two recheck attempts” can ask the same module twice, and how well someone does the second time is a property of the learner, not the rule — so it is shown both ways. Same assumes a 2/3 stays a 2/3; one better assumes they get one more right, having just been told they missed one. Every other rule is unaffected by the choice, which is itself a useful check.

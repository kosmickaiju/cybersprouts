# Purpose
This is a cybersecurity learning platform currently titled Cybersprouts. Essentially, Cybersprouts will serve as a cybersecurity "cousin" to roadmap.sh, the website that lays out a roadmap for aspiring software engineers. The platform walks aspiring cybersecurity professionals through the basics of cybersecurity and related concepts to provide them with a strong foundational knowledge to build off of. 
## Who and Why
This platform is built for individuals who are newer to cybersecurity and are seeking a more structured approach to learning security concepts and discovering their niche in the field. Both those with and without prior tech experience should be able to utilize this platform. As cybersecurity is becoming a larger and more sought-after field despite not necessarily being an entry-level tech field, especially with many software engineers pivoting into security with AI playing a bigger role in SWE, it is becoming more critical for people to know just how to break into the cybersecurity world.

## Must/Should/Won't
The Cybersprouts platform must follow this curriculum flow: basic security concepts (examples include what is cybersecurity, the CIA triad, social engineering, and jobs in cybersecurity) -> intro to programming in python (python basics, security scripting, secure coding principles) -> intro to the terminal (bash vs zsh, basic cli tools) -> intro to operating systems (windows and linux) -> networking fundamentals (types of networks, subnetting, tcp/ip, ports, etc). As a note, the items in the parentheses are simply suggestions for what will be in each module rather than a strict list of what will be taught. Other concepts may be added or removed at my discretion. After the networking module is complete, the roadmap splits into two and the user can choose to go down the blue team/defensive security path (SOC work, IAM, GRC concepts) or the red team/offensive security path (pentesting concepts and CTF prep). Users can ultimately do both paths, but they branch off from each other after the networking module. Additionally, the platform must have an independent AI security module that can be accessed at any moment during the roadmap and users can go between this AI security module and the general roadmap modules. 

The Cybersprouts platform should have a very sleek look, preferably a neutral dark palette throughout the platform. Additionally, to play into the Cybersprouts name, there should also be some reference to plants/sprouts throughout the platform. However, once the user splits into red team/blue team, the palette changes to match what team the user is exploring - a red palette for red team work, and a blue palette for blue team work. To ensure that those with prior tech experience can avoid relearning basic concepts, Cybersprouts should start with an optional placement test for concepts up until the red/blue team split such that those with previous experience can start specializing earlier.

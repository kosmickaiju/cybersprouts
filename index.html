The shared roots

Everyone walks the same eight modules first. They're deliberately ordered — each one is the prerequisite the next assumes you already have.

Then the path forks three ways

Named for the security colour wheel: red breaks it, yellow builds it, blue defends it. The whole interface changes colour with you — and you can come back and walk another branch whenever you want.
